Java

A complete introduction to the language, aimed at everything a junior backend developer is expected to know before touching a framework.

How to use this course

Lessons 1–8 are the language mechanics: syntax, types, control flow, arrays and strings. Lessons 9–12 are object-oriented programming, which is what most Java code is made of. Lessons 13–19 are the standard library and the tools you will use daily. Lessons 20–22 are the professional habits: tests, builds, and working in a team.

Read a lesson, then type its code out yourself — do not copy-paste. Every lesson ends with a short practice task; doing those is where the learning actually happens.

Target version Everything here uses Java 21 (a long-term-support release). Anything newer than Java 8 is flagged when it appears, because plenty of workplace code still runs on Java 8 or 11.
