Arrays

Fixed-size, indexed blocks of memory. You will use List far more often in application code, but arrays are underneath everything and appear in every API and interview.

Creating an array

int[] numbers = new int[5];               // 5 slots, all 0
String[] names = {"Ada", "Linus", "Grace"};  // literal, size inferred
double[] prices = new double[]{1.5, 2.0};    // explicit form, needed when not declaring

int[] wrong = new int[];                  // error: size or initialiser required

int numbers[] also compiles (C-style) but nobody writes it that way in Java.

Elements start at the type's default: 0 for numbers, false for booleans, null for references.

Reading and writing

String[] names = {"Ada", "Linus", "Grace"};

names[0]              // "Ada"      indexing starts at 0
names[2]              // "Grace"
names.length          // 3          a field, not a method — no brackets
names[names.length-1] // last element
names[1] = "Linus T"; // assignment

names[3]              // ArrayIndexOutOfBoundsException at runtime

The size is fixed at creation. To "grow" an array you create a bigger one and copy — or use an ArrayList, which does that for you (lesson 14).

Iterating

// indexed: when you need the position
for (int i = 0; i < names.length; i++) {
    System.out.println(i + ": " + names[i]);
}

// enhanced: when you only need the values
for (String name : names) {
    System.out.println(name);
}

// backwards
for (int i = names.length - 1; i >= 0; i--) { ... }

The Arrays utility class

import java.util.Arrays;

int[] nums = {5, 2, 9, 1};

Arrays.toString(nums)          // "[5, 2, 9, 1]"  — println(nums) prints a useless [I@1b6d3586
Arrays.sort(nums);             // sorts in place → [1, 2, 5, 9]
Arrays.binarySearch(nums, 5)   // 2  (only valid on a sorted array)
Arrays.fill(nums, 0);          // every element becomes 0
int[] copy = Arrays.copyOf(nums, 6);        // longer copy, padded with 0
int[] part = Arrays.copyOfRange(nums, 1, 3); // elements 1..2
Arrays.equals(a, b)            // element-by-element comparison
Arrays.stream(nums).sum()      // 17  — streams in lesson 16
== does not compare contents a == b asks whether the two variables point at the same array object. Use Arrays.equals (or Arrays.deepEquals for nested arrays).

Copying

int[] original = {1, 2, 3};

int[] alias = original;                       // NOT a copy — same array, two names
int[] copy1 = Arrays.copyOf(original, 3);     // real copy
int[] copy2 = original.clone();               // real copy
System.arraycopy(original, 0, copy3, 0, 3);   // low-level, fastest

All of these are shallow: copying a Person[] copies the references, so both arrays share the same Person objects.

Multidimensional arrays

int[][] grid = new int[3][4];        // 3 rows, 4 columns, all zeros
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

matrix[1][2]          // 6
matrix.length         // 2  (rows)
matrix[0].length      // 3  (columns in row 0)

for (int[] row : matrix) {
    System.out.println(Arrays.toString(row));
}

A 2D array is really an array of arrays, so rows can have different lengths ("jagged"):

int[][] jagged = new int[3][];
jagged[0] = new int[]{1};
jagged[1] = new int[]{1, 2, 3};
jagged[2] = new int[]{1, 2};

Arrays of objects

String[] words = new String[3];      // three nulls
System.out.println(words[0].length()); // NullPointerException — nothing created yet

words[0] = "hello";                  // now it points at a String

Creating an array of a reference type creates the slots, not the objects.

Classic array algorithms

// maximum
int max = nums[0];
for (int n : nums) if (n > max) max = n;

// linear search — returns the index or -1
static int indexOf(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) if (arr[i] == target) return i;
    return -1;
}

// reverse in place
for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
    int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
}

Know these by hand — then use Arrays and streams in real code, because the library version is tested and yours is not.

Practice
  1. Fill an array with 10 random integers, then print the minimum, maximum and average.
  2. Write reverse(int[] arr) that returns a new reversed array, leaving the original untouched. Prove the original is untouched.
  3. Count how many times each letter A–Z appears in a string, using an int[26].
  4. Build a 3×3 tic-tac-toe board as char[][], print it, and write a method that detects a win in any row.
  5. Remove duplicates from a sorted int[] and return the shortened array.
