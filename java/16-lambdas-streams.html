Lambdas and streams

Java 8's headline feature and now the default way to express data transformations. Modern Java code is full of it, so reading it fluently matters as much as writing it.

Lambdas

A lambda is a compact implementation of a functional interface — an interface with exactly one abstract method.

// the same thing, three ways
Runnable r1 = new Runnable() {
    @Override public void run() { System.out.println("hi"); }
};
Runnable r2 = () -> System.out.println("hi");
Runnable r3 = () -> {
    System.out.println("hi");
    System.out.println("multiple statements need braces");
};
(String s) -> s.length()      // explicit parameter type
s -> s.length()               // inferred — the usual style
(a, b) -> a + b               // two parameters
() -> 42                      // none
x -> { return x * 2; }        // block body needs an explicit return

A lambda can read local variables from the enclosing scope, but they must be final or effectively final (never reassigned):

int factor = 3;
Function<Integer, Integer> times = n -> n * factor;   // fine
// factor = 4;   ← adding this makes the lambda above fail to compile

The standard functional interfaces

InterfaceMethodMeaning
Function<T,R>R apply(T)transform a value
Predicate<T>boolean test(T)a yes/no question
Consumer<T>void accept(T)do something with a value
Supplier<T>T get()produce a value on demand
BiFunction<T,U,R>R apply(T,U)two inputs, one output
UnaryOperator<T>T apply(T)same type in and out
BinaryOperator<T>T apply(T,T)combine two of a kind
Predicate<String> isLong = s -> s.length() > 5;
Predicate<String> startsA = s -> s.startsWith("a");
isLong.and(startsA).test("abcdefg");    // true — predicates compose
isLong.negate().test("hi");             // true

Function<Integer,Integer> twice = n -> n * 2;
Function<Integer,Integer> plus3 = n -> n + 3;
twice.andThen(plus3).apply(5);          // 13
twice.compose(plus3).apply(5);          // 16

Method references

s -> s.toUpperCase()          →   String::toUpperCase       // instance method of the parameter
s -> System.out.println(s)    →   System.out::println       // instance method of an object
s -> Integer.parseInt(s)      →   Integer::parseInt         // static method
s -> new StringBuilder(s)     →   StringBuilder::new        // constructor

Use one when the lambda does nothing but call an existing method.

Streams

A stream is a pipeline over a source. It does not store data and does not modify the source; it describes a computation.

List<String> result = names.stream()          // 1. source
        .filter(n -> n.length() > 3)          // 2. intermediate (lazy)
        .map(String::toUpperCase)             //    intermediate
        .sorted()                             //    intermediate
        .toList();                            // 3. terminal — runs the whole pipeline

Nothing happens until the terminal operation. A stream can be consumed only once.

Creating streams

list.stream()
Arrays.stream(array)
Stream.of("a", "b", "c")
IntStream.range(0, 10)              // 0..9
IntStream.rangeClosed(1, 10)        // 1..10
Files.lines(path)                   // stream of lines, remember to close
Stream.iterate(1, n -> n * 2).limit(10)
map.entrySet().stream()

Intermediate operations

.filter(p -> p.age() >= 18)          keep matching elements
.map(Person::name)                   transform each element
.flatMap(order -> order.items().stream())   flatten nested collections
.distinct()                          remove duplicates (uses equals)
.sorted()                            natural order
.sorted(Comparator.comparing(Person::age))
.limit(10)   .skip(5)                pagination
.peek(System.out::println)           debugging only
.takeWhile(n -> n < 100)             Java 9+
.dropWhile(n -> n < 100)

Terminal operations

.toList()                            Java 16+, immutable  ← default choice
.collect(Collectors.toList())        older equivalent
.collect(Collectors.toSet())
.forEach(System.out::println)
.count()
.anyMatch(p -> p.age() > 65)   .allMatch(...)   .noneMatch(...)
.findFirst()   .findAny()             → Optional
.min(comparator)   .max(comparator)   → Optional
.reduce(0, Integer::sum)
.mapToInt(Person::age).sum()
.mapToInt(Person::age).average()      → OptionalDouble
.mapToInt(Person::age).summaryStatistics()   // count, sum, min, max, average at once

Collectors worth knowing

// join into a string
String names = people.stream().map(Person::name).collect(Collectors.joining(", "));

// group
Map<String, List<Person>> byCity =
    people.stream().collect(Collectors.groupingBy(Person::city));

// group and count
Map<String, Long> countByCity =
    people.stream().collect(Collectors.groupingBy(Person::city, Collectors.counting()));

// group and aggregate
Map<String, Double> avgAgeByCity =
    people.stream().collect(Collectors.groupingBy(Person::city,
                            Collectors.averagingInt(Person::age)));

// split in two
Map<Boolean, List<Person>> adults =
    people.stream().collect(Collectors.partitioningBy(p -> p.age() >= 18));

// build a map
Map<Long, Person> byId =
    people.stream().collect(Collectors.toMap(Person::id, p -> p));
toMap throws on duplicate keys IllegalStateException: Duplicate key. Supply a merge function when duplicates are possible: Collectors.toMap(Person::city, Person::name, (a, b) -> a).

Before and after

// imperative
List<String> result = new ArrayList<>();
for (Person p : people) {
    if (p.age() >= 18 && p.city().equals("Berlin")) {
        result.add(p.name().toUpperCase());
    }
}
result.sort(Comparator.naturalOrder());

// declarative
List<String> result = people.stream()
        .filter(p -> p.age() >= 18)
        .filter(p -> p.city().equals("Berlin"))
        .map(p -> p.name().toUpperCase())
        .sorted()
        .toList();

Pitfalls

  • Side effects. Do not mutate an outside collection from inside forEach or map; collect the result instead.
  • Streams are single-use. Reusing one throws IllegalStateException.
  • Not always clearer. A simple loop over three elements does not need a pipeline. Debugging a long chain is harder than stepping through a loop.
  • parallelStream() is not free speed. It helps only for large datasets and CPU-bound, side-effect-free work. Measure before using it; never use it for I/O.
  • Nulls. Streams do not like them. Filter them out early: .filter(Objects::nonNull).
Practice
  1. From a list of Product, get the names of products under €20, sorted alphabetically.
  2. Compute the total value of stock (price × quantity) with a stream.
  3. Group orders by status and count each group.
  4. Find the oldest person in each city, returning Map<String, Optional<Person>>.
  5. Take a list of sentences and produce a sorted list of distinct words using flatMap.
  6. Rewrite three loops from earlier lessons as streams — then decide honestly which version reads better.
