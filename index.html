Learning

A folder per subject, a page per lesson. Read them in order, or jump to whatever you need.

How this site is organised

Every subject lives in its own folder next to this page. A folder holds an index.html overview plus one HTML page per lesson, and folders can nest (for example java-spring/react/) when a subject grows sub-topics.

Navigation is generated, not hand-written. assets/courses.js lists the courses and their lessons; assets/nav.js turns that list into the breadcrumb, sidebar, card grids and prev/next links on every page.

Adding a lesson

1. Copy an existing lesson page into the course folder.
2. Update <title> and the data-page attribute on <body>.
3. Add an entry to the course's lessons array in assets/courses.js.

Adding a subject

1. mkdir python
2. Create python/index.html (copy a course overview page, change data-course).
3. Append a new course object to window.COURSES in assets/courses.js.
Reading the pages Open index.html in any browser — there is no build step, no server and no dependencies.
