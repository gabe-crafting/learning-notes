Before you start

This course assumes the Java course: classes and interfaces, generics, collections, lambdas, exceptions, JUnit and Maven. Spring is not a different language, but it leans hard on annotations, interfaces and generics, so shaky Java makes Spring feel like magic. It is not magic.

Versions Spring Boot 3.x on Java 21. Spring Boot 3 moved from javax.* to jakarta.* imports — if a tutorial you find online uses javax.persistence, it is written for Boot 2 and the imports will not compile.

The shape of the course

Lessons 1–4 are the container: what Spring does for you and how you configure it. Lessons 5–7 are the web layer. Lessons 8–10 are the database. Lessons 11–15 are the things that turn a demo into a service someone can run in production. Lesson 16 is a capstone that puts all of it together.

The mental model to hold on to

A Spring Boot application is a box (the application context) full of objects (beans) that Spring creates for you and wires together. Nearly every annotation you will meet does one of three things:

  1. Puts an object in the box — @Component, @Service, @Repository, @Configuration + @Bean.
  2. Takes an object out of the box — constructor injection, @Autowired.
  3. Asks Spring to wrap an object in behaviour — @Transactional, @Cacheable, @PreAuthorize, @Scheduled.

Whenever something surprises you, ask which of those three is happening.
